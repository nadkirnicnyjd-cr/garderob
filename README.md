# Секонд-охота
1. Создайте репозиторий на GitHub, загрузите все файлы (включая папку .github).
2. Settings -> Pages -> Deploy from branch -> main / (root).
3. Actions -> update -> Run workflow (дальше сам, 2 раза в день).
4. Сайт: https://ВАШ_НИК.github.io/ИМЯ_РЕПО/
Локально: `python scraper.py`, затем `python -m http.server` и открыть localhost:8000
Магазины добавляются в stores.csv (тип 1/2/3 или ?)
